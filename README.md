# ANGRY NEIGHBOR: OLD HARDMODE WEBGL

Минималистичный сайт-витрина для версий Unity WebGL.

## Как запустить сайт

Просто откройте `index.html` в любом браузере.

## Структура

- `index.html` — главная страница (название, кнопки версий, ссылки на тг).
- `css/style.css` — стили и адаптив.
- `js/app.js` — показ скриншотов при наведении на кнопку.
- `assets/images/` — скриншоты для версий.
- `games/v0.1/` — сюда положить билд Unity WebGL версии 0.1.
- `games/v0.8/` — сюда положить билд Unity WebGL версии 0.8.

## Как заменить скриншоты и ссылки на телеграм

1. **Telegram**: откройте `index.html` и внизу в тегах `<a>` замените ссылки `https://t.me/...` и названия на свои.
2. **Скриншоты**: положите свои картинки в `assets/images/`, а в `index.html` в кнопках поменяйте атрибут `data-img="assets/images/ваша_картинка.png"`.

## Загрузка на GitHub Pages

1. Загрузите файлы в репозиторий на GitHub.
2. Перейдите в **Settings** -> **Pages**.
3. В **Branch** выберите ветку `main` и нажмите **Save**.
